# Mission and story presentation — phase 2

Reviewed 2026-08-26. This phase reorganizes existing, source-reviewed material; it does not add scientific claims or a new content category.

## Consistent evidence flow

Mission records now open with a compact evidence path linking to the brief, instrument evidence, chronology, and official sources. Objectives are labeled separately from narrative context. Results carry a curated-evidence label, and continuing status is isolated in the shared source-note pattern so it cannot be mistaken for an instrument result. Repeated provenance language was shortened while the review date, next review date, and official NASA links remain visible.

Science stories use the same orientation pattern for chapters, synthesis, chronology, and sources. Chapter captions explicitly separate the evidence class from its explanatory text, shared definitions use semantic description lists, and source blocks lead directly to the matching guided-learning track. Mission continuations likewise connect reviewed records to related stories, live data, and guided practice where those relationships already exist.

## Reading and accessibility evidence

Long-form prose retains a bounded reading measure and shared content line height. In-page links meet the shared 44-pixel control target, work without scripting, and expose descriptive navigation labels. Mission and story routes are included in automated axe checks. Data integrity tests ensure every story's learning handoff resolves to an existing track.
