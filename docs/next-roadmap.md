# Evidence-driven next roadmap

This sequence was selected in the 2026-08 monthly review. Scores and order are hypotheses, not promises; accessibility, privacy, security, and data-integrity barriers override them.

1. **Stale-state comprehension:** expose normalized stale-fallback status in one instrument, test it with keyboard and screen-reader users, then expand only if comprehension improves.
2. **Learning-effectiveness sample:** run three de-identified two-session studies and publish only aggregate delayed comprehension and evidence-recall results.
3. **First-visit terminology:** test `live`, `latest available`, `curated`, and `calculated` with five new participants and change labels only for repeated misconceptions.
4. **Thirty-day operating review:** evaluate the first complete reliability, route-performance, and asset-budget windows before changing thresholds or infrastructure.
5. **Contract and content refresh:** recheck official NASA contracts quarterly and complete scheduled mission/content reviews without weakening validation.

Each item needs an evidence link, owner, acceptance criterion, and updated score before implementation. Re-score after every monthly review and release; document rejected ideas as well as selected work.
