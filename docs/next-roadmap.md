# Appearance and usability roadmap

Updated 2026-09-15. This cycle improves existing interfaces without adding features.
The September 8 implementation history remains recorded in the README and phase evidence.

1. **Complete — Phase 1: Bring content forward:** compact the dashboard hero and archive introductions; place mission records and saved content ahead of supporting panels. Evidence: [content-first layouts](content-first-layouts-phase-1.md).
2. **Complete — Phase 2: Improve readability and consistency:** standardized shared typography, heading spacing, controls, secondary text, and evidence badges. Evidence: [readability and consistency](readability-consistency-phase-2.md).
3. **Complete — Phase 3: Simplify existing interactions:** clarified APOD actions and saved states, mission and Flight Log filters, and empty/error guidance. Evidence: [interaction clarity](interaction-clarity-phase-3.md).
4. **Complete — Phase 4: Polish mobile and keyboard use:** bounded mobile navigation, restored Escape focus, enlarged key touch targets, preserved mobile APOD framing, and moved persistent notices out of the reading area. Evidence: [mobile and keyboard polish](mobile-keyboard-phase-4.md).
5. **In progress — Phase 5: Validate and consolidate:** test APOD browsing, mission filtering, finding saved content, and trivia with real participants; fix observed barriers and refresh visual evidence. Automated browser review and visual refresh are prepared; participant recruitment remains pending. Maintainer checks are not participant research. See [validation and session guide](appearance-validation-phase-5.md).

For each phase, review desktop/mobile layouts, run required quality gates, update evidence, and commit and push only after validation. Existing scientific and reliability maintenance remains tracked separately.
