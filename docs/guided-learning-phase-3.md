# Guided learning and progress — Phase 3

## Tracks

Three structured tracks connect existing evidence rather than duplicating it: ancient Mars habitability, the Sun–Earth connection, and cosmic observatories. Each states an objective, audience, estimated session length, four linked resources, a source-backed knowledge check, a reflection prompt, and official NASA sources.

## Local progress and portability

The versioned `mission-control:learning-progress:v1` record stores only completed step IDs, passed checks, bounded reflections, and update timestamps. Runtime validation limits it to 12 tracks, 12 step IDs per track, and 1,000 reflection characters. It is included in the existing whitelisted Mission Control backup, can be separately exported as JSON, and has an explicit reset control. Nothing is transmitted or synchronized.

## Educator and print format

Each track includes a guided-session structure for opening discussion, paired investigation, retrieval practice, and evidence-based reflection. Print styles remove application navigation and interactive controls, preserve objectives and official links, provide writing space, use black-on-white output, and retain a two-column activity sequence when paper width allows.

## Learning integrity

Knowledge-check explanations link directly to official NASA mission or science sources. Completion means the learner marked all four resources, passed the check, and saved a reflection; it is not a credential or assessment of mastery. Tests cover validation, reload persistence, local export/reset, sourced checks, and backup inclusion.
